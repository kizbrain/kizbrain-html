    프로그램 사용법

    학습 방식(사이드바 맨 위)

    운지법 배우기
    주판알을 손가락으로 놓고 터는 법을 순서대로 익힙니다.
    단계별 학습
    급수 순서대로(1~32단계) 문제를 풀며 실력을 늘립니다.
    자유 모드
    연산·자릿수·항수를 직접 정해서 연습합니다.
    급수시험
    실제 급수시험처럼 시간을 재며 풉니다.
    🖨 문제지 인쇄
    연습용 문제지를 인쇄해서 종이로 풉니다.
    📖 프로그램 사용법
    지금 보고 계신 이 화면입니다.

    여러 화면에서 공통으로 쓰는 것

    단계 선택(드롭다운)
    지금 풀 급수·단계를 고릅니다.
    속도 조절
    숫자가 넘어가는 빠르기를 정합니다. 값이 클수록 빨라집니다.
    시작 카운트다운
    문제 풀이가 실제로 시작되기 전 준비 시간(초)입니다.
    정답 확인 방식
    입력해서 자동 채점할지, 직접 맞았다/틀렸다 눌러서 채점할지 정합니다.

    자유 모드 전용

    연산(+ − × ÷)
    어떤 계산으로 문제를 낼지 고릅니다.
    자릿수 / 항수
    숫자가 몇 자리인지, 몇 개를 더하고 뺄지 정합니다.

    급수시험 전용

    유형(주산/암산)
    주판을 보며 풀지, 머릿속으로만 풀지 정합니다.
    급수
    몇 급 시험인지 고릅니다. 급수마다 난이도·문제 구성이 다릅니다.
    연산
    덧셈과뺄셈 / 곱셈 / 나눗셈 중 무엇을 시험 볼지 정합니다.
    제한시간(표준/직접 설정)
    급수별 표준 시간을 쓸지, 원하는 시간으로 직접 정할지 고릅니다.
    🖥 온라인 시험
    화면에서 바로 시간을 재며 시험을 봅니다.
    🖨 시험지 출력
    시험지를 종이로 인쇄해서 오프라인으로 시험 봅니다.

    운지법 배우기 전용(화면 하단 버튼)

    ◀ 이전
    바로 앞 숫자로 돌아갑니다.
    문제 출제(다음) ▶
    다음 숫자를 놓거나, 계산 문제라면 다음 항을 보여줍니다.
    ▶ 자동 출제
    정해진 문제 수(10개)까지 자동으로 이어서 재생합니다.
    진행
    지금 몇 번째 문제인지 보여줍니다.
    ♾ 무한출제
    10개로 멈추지 않고 계속 이어서 재생합니다(수업 중 계속 틀어둘 때 사용).
    🔊 소리
    알이 자리 잡을 때 나는 소리를 켜고 끕니다.

    상단바

    학원명
    인증할 때 등록한 학원명이 고정으로 표시됩니다.
    반 이름 / 학생 이름
    지금 문제를 푸는 반과 학생을 입력합니다. 기록이 이 이름으로 저장됩니다.
    새 학생
    학생 이름만 지웁니다(반 이름은 그대로 유지).
    종료
    반 이름과 학생 이름을 모두 지웁니다.
    📊 학습 현황
    학생별 정답률·추천 단계를 보고, 오답을 다시 풀거나 기록을 CSV로 저장합니다.

    학습 현황 화면

    🔁 오답 다시 풀기
    지금 학생이 틀렸던 문제만 모아서 다시 풉니다.
    학습기록(CSV)
    지금 학생의 기록만 파일로 저장합니다.
    🔽 오늘 학생 보기
    오늘(0시~24시) 문제를 푼 학생 목록을 펼칩니다. 학생을 누르면 그 학생에 대해 오답 다시 풀기·기록 다운로드를 바로 할 수 있습니다.
    전체 기록 CSV
    지금까지 쌓인 모든 학생의 기록을 한 파일로 저장합니다.
    기록 모두 지우기
    저장된 모든 기록을 삭제합니다. 되돌릴 수 없습니다.
